### 晚夜（指揮位 / 核心節奏）

遊戲定位：指揮、主牽制常用角色：律師負責：開圖、報點、決策

個性：表面：強勢、嘴硬、控制欲強實際：很在意隊友、會默默配合特點：不愛承認，但會「做」

說話風格：短句、直接：「排了」「走」「可以拖」被戳會反擊，但不會真的翻臉

關鍵特徵：會等人，但嘴上說是「戰術」會稱讚，但很小聲（例如：「漂亮」）

人物弧線（目前）：👉 從「單向指揮」 → 開始「接受隊友」

### 古文（氣氛＋變數位）

遊戲定位：干擾 / 營運 / 不穩定因素常用角色：冒險家、昆蟲學者

個性：表面：嘴砲、愛鬧、很吵實際：觀察力強、時機感好特點：嘴最兇，但常常做對的事

說話風格：嘲諷＋自信：「我很穩」「看到沒」常打斷別人節奏（包含現實）

關鍵特徵：會亂來，但通常「剛好成功」是最會打破尷尬的人

人物弧線：👉 從「純搞笑」 → 被認可為「真的有實力」

### 小光（穩定支援 / 情緒調節）

遊戲定位：救人位 / 補位常用角色：守墓人

個性：表面：開朗、愛笑、好相處實際：觀察氣氛、會幫忙緩和關係特點：隊伍的「潤滑劑」

說話風格：輕鬆、帶笑：「真的欸」「超順」常補一句讓氣氛變好

關鍵特徵：很少衝突會默默把局補穩

人物弧線：👉 從「旁邊的人」 → 成為「讓隊伍舒服的關鍵」

### 家麟（沉穩核心 / 隱性主軸）

遊戲定位：穩定支援 / 節奏補強常用角色：舞女、心理學家、拉拉隊員

個性：表面：安靜、話少實際：很準、觀察力極高特點：說話不多，但幾乎都在關鍵點

說話風格：極簡：「我在門」「可以」「我來」很少情緒，但很穩

關鍵特徵：常在關鍵時刻出現是唯一能讓晚夜「自然配合」的人

人物弧線：👉 從「背景角色」 → 慢慢變成「情感核心」
